<h2 id="bridging-web2-web3">Bridging Web2 Enterprise Directory Services with Web3</h2>

Fortune 500 enterprises transitioning to decentralized Web3 workflows face a major hurdle: **employees already possess authenticated enterprise identities inside Okta, AWS IAM Identity Center, or Azure Active Directory (Entra ID).**

Requiring enterprise employees to manage raw seed phrases creates unacceptable security risks. Praman Identity Bridge allows organizations to convert SAML 2.0 assertion tokens into W3C Verifiable Credentials and Decentralized Identifiers (DIDs) using RSA-to-SNARK zero-knowledge proofs.

<Callout variant="info" title="Zero Enterprise Modification">
  Your existing Azure AD or AWS IAM configuration requires no code changes. Praman acts as an OIDC identity provider proxy.
</Callout>

<h2 id="oidc-rsa-proofs">Architecture: OIDC RSA Signature Proofs</h2>

When an employee logs into Azure AD, Azure signs a JWT ID token using an RSA-2048 private key. The Praman Bridge verifies the RSA-2048 signature inside a zk-SNARK circuit:

<CodeBlock language="typescript" filename="enterprise_bridge.ts" code={`import { PramanEnterpriseBridge } from '@praman/sdk/enterprise';

const bridge = new PramanEnterpriseBridge({
  tenantId: "azure-tenant-94a3b8",
  clientId: "praman-app-client-id",
  redirectUri: "https://enterprise.praman.network/callback"
});

// Convert OIDC Token into ZK Verifiable Credential
const credential = await bridge.exchangeOidcForZkCredential({
  oidcToken: userJwtToken,
  claimToProve: "email_domain",
  expectedDomain: "company.com"
});

console.log("W3C Verifiable Credential DID:", credential.did);`} />
