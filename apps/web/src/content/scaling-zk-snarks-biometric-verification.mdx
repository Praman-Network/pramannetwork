<h2 id="the-proving-bottleneck">The Proving Bottleneck in On-Chain Identity</h2>

Standard Groth16 proof generation for biometric feature vectors historically required over **12 seconds** on consumer hardware. For web3 applications requiring sub-second biometric authentication, this latency rendered zero-knowledge identity impractical for real-world deployment.

At Praman Network, our goal was clear: achieve **sub-500ms proving times** directly in browser and mobile environments without sacrificing cryptography strength or delegating private key material to third-party provers.

<Callout variant="info" title="Why Groth16?">
  Groth16 remains the most gas-efficient proving system for on-chain verification on EVM chains, with constant-size proofs (~192 bytes) and O(1) verification complexity (~200k gas).
</Callout>

<h2 id="algorithmic-optimizations-in-circom">Algorithmic Optimizations in Circom</h2>

Our breakthrough came from restructuring the distance metric calculation inside the Circom circuit. Instead of raw Euclidean distance, we transformed the high-dimensional feature vector matching into a Poseidon-compressed inner product check over BN254.

<CodeBlock language="circom" filename="biometric_verify.circom" code={`pragma circom 2.1.6;

include "../node_modules/circomlib/circuits/poseidon.circom";
include "../node_modules/circomlib/circuits/comparators.circom";

template BiometricVerify(n) {
    signal input features[n];
    signal input salt;
    signal input storedCommitment;
    signal input threshold;
    
    signal output isValid;

    // 1. Poseidon Hash of biometric feature vector
    component hasher = Poseidon(n + 1);
    for (var i = 0; i < n; i++) {
        hasher.inputs[i] <== features[i];
    }
    hasher.inputs[n] <== salt;

    // 2. Enforce hash commitment match
    hasher.out === storedCommitment;

    // 3. Distance metric threshold check
    component comp = LessEqThan(32);
    comp.in[0] <== threshold;
    comp.in[1] <== 50; // Max allowed Hamming variance
    
    isValid <== comp.out;
}`} />
