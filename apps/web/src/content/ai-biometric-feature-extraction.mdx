<h2 id="privacy-ai">Privacy in the Age of AI Biometrics</h2>

Modern facial and fingerprint authentication relies on deep neural networks to project raw sensor readings into 512-dimensional vector embeddings. However, storing raw embedding vectors in a centralized database exposes users to reverse-engineering attacks where facial images can be reconstructed from embedding vectors.

Praman Protocol combines **Lightweight Mobile Neural Networks** with **Fully Homomorphic Encryption (FHE)** and **zk-SNARKs** to ensure raw biometric data never leaves the client's local device memory.

<Callout variant="info" title="Zero Image Exposure">
  Neither raw camera frames nor unencrypted feature vectors are ever written to disk or sent across the network.
</Callout>

<h2 id="pipeline">The Feature Extraction Pipeline</h2>

<CodeBlock language="python" filename="feature_extractor.py" code={`import torch
import torch.nn as nn

class PrivacyBiometricEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        # Mobile-optimized MobileNetV3 backbone
        self.backbone = torch.hub.load('pytorch/vision', 'mobilenet_v3_small')
        self.projection = nn.Linear(1000, 512)
        
    def forward(self, face_tensor):
        features = self.backbone(face_tensor)
        embeddings = self.projection(features)
        # L2 Normalization for cosine similarity matching
        norm_embeddings = torch.nn.functional.normalize(embeddings, p=2, dim=1)
        return norm_embeddings`} />
