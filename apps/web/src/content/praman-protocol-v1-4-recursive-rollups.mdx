<h2 id="protocol-overview">Protocol Overview: Scaling Identity Verification</h2>

Praman Protocol v1.4 introduces **Recursive SNARK Aggregation** directly into our Layer-2 identity rollup network. By folding 64 individual biometric verification proofs into a single recursive meta-proof, Praman reduces per-verification gas costs on Ethereum Mainnet to less than **2,200 gas**.

<Callout variant="info" title="v1.4 Milestone">
  Praman v1.4 handles over 24,000 identity verifications per second (TPS) across our decentralized node consensus network.
</Callout>

<h2 id="recursive-circuit">Recursive Circuit Design</h2>

The core recursive circuit `RecursiveBatchVerifier.circom` takes `N` inner Groth16 proofs and verifies their pairing equations recursively inside a single outer proof:

<CodeBlock language="rust" filename="recursive_aggregator.rs" code={`use praman_crypto::groth16::{Proof, VerifyingKey};
use praman_recursive::RecursiveEngine;

pub fn aggregate_proofs(
    proofs: Vec<Proof>,
    vkey: &VerifyingKey
) -> Result<Proof, AggregationError> {
    let mut engine = RecursiveEngine::new();
    
    for proof in proofs {
        engine.accumulate_pairing(&proof, vkey)?;
    }
    
    // Finalize recursive rollup proof
    let meta_proof = engine.finalize_batch_proof()?;
    Ok(meta_proof)
}`} />
